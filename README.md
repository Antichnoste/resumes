# Резюме

Исходники находятся в корне: `ML.tex`, `ML_VK.tex`, `Back.tex` и `Back_python.tex`. Общее оформление — в `resume.cls`.

## Сборка на GitHub

При отправке изменений в ветку `main` GitHub Actions собирает четыре PDF. Запуск также доступен вручную: **Actions → Build resumes → Run workflow**. После успешной сборки откройте запуск и скачайте архив **resumes** в разделе **Artifacts**. Артефакт хранится 30 дней и доступен пользователям с доступом к репозиторию; он не предназначен для публичной отправки работодателям.

Для отправки резюме загрузите нужный PDF в облачное хранилище и настройте доступ получателю. Репозиторий должен оставаться приватным. GitHub Pages этим workflow не публикуется.

## Локальная сборка

Установите `pdflatex` и пакеты LaTeX, включая поддержку русского языка и `fontawesome5`. Например, в Ubuntu нужны пакеты `texlive-latex-base`, `texlive-latex-recommended`, `texlive-latex-extra`, `texlive-lang-cyrillic`, `texlive-fonts-recommended` и `texlive-fonts-extra` (последний большой).

```bash
./scripts/build.sh
```

Скрипт дважды собирает каждое резюме и сохраняет PDF в `docs/`. Служебные файлы создаются во временном каталоге. Если сборка прервалась, оставшиеся PDF могут быть устаревшими; исправьте ошибку и запустите скрипт заново. PDF не хранятся в Git.
